# PuraMax GOLD — Production Tracking System

  ## Quick Start

  ```bash
  npm install
  npm run dev
  ```

  Then open http://localhost:5173 in your browser.

  ## Login

  - Enter any factory name (e.g. "Al-Rashid Factory")
  - Choose role: Owner / Production Manager (full access)

  ## Pages

  - Dashboard, Orders, New Orders, Movements, Scale, Print Queue
  - Designer, Worker, Models, Master Data, Alerts, Analytics, Settings
  - **New:** Tree Build, Audit Log

  ## Tech Stack

  React 19 + Vite + Tailwind CSS v4 + Wouter + TanStack Query
